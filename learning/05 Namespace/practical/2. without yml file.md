### Get namespaces

```bash
kubectl get namespace
```

or 

```bash
kubectl get ns
```

```bash
ubuntu@DESKTOP-5RB8M36:~/kubernetes$ kubectl get namespace
NAME                 STATUS   AGE
default              Active   23h
kube-node-lease      Active   23h
kube-public          Active   23h
kube-system          Active   23h
local-path-storage   Active   23h
ubuntu@DESKTOP-5RB8M36:~/kubernetes$
```

### Create namespaces

```bash
kubectl create ns ngnix
```

```bash
ubuntu@DESKTOP-5RB8M36:~/kubernetes$ kubectl create ns ngnix
namespace/ngnix created
ubuntu@DESKTOP-5RB8M36:~/kubernetes$ kubectl get ns
NAME                 STATUS   AGE
default              Active   23h
kube-node-lease      Active   23h
kube-public          Active   23h
kube-system          Active   23h
local-path-storage   Active   23h
ngnix                Active   12s
ubuntu@DESKTOP-5RB8M36:~/kubernetes$
```
